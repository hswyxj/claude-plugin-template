# 测试生成 Skill

为现有代码自动生成测试用例。

## 使用场景

- 新功能开发后补充测试
- 重构前增加测试覆盖
- 提升代码可测试性

## 支持的测试框架

- Vitest
- Jest
- React Testing Library
- Cypress
- Playwright

## 测试类型

### 单元测试
- 纯函数测试
- 工具函数测试
- 状态管理测试

### 组件测试
- 渲染测试
- 交互测试
- Props 测试

### 集成测试
- API 测试
- 数据流测试
- 页面流程测试

## 测试模式

### AAA 模式
```typescript
describe('calculateTotal', () => {
  it('should calculate total with tax', () => {
    // Arrange
    const items = [{ price: 100 }, { price: 200 }];
    const taxRate = 0.1;

    // Act
    const result = calculateTotal(items, taxRate);

    // Assert
    expect(result).toBe(330);
  });
});
```

### Given-When-Then
```typescript
describe('User Login', () => {
  it('should login successfully with valid credentials', () => {
    // Given
    const credentials = { email: 'test@example.com', password: '123456' };

    // When
    const result = login(credentials);

    // Then
    expect(result.success).toBe(true);
    expect(result.token).toBeDefined();
  });
});
```

## 执行流程

1. 读取目标代码
2. 分析函数/组件接口
3. 识别测试场景
4. 生成测试代码

## 输出格式

```typescript
// Generated by test-generator skill

import { describe, it, expect } from 'vitest';
import { calculateTotal } from './calculator';

describe('calculateTotal', () => {
  describe('happy path', () => {
    it('should return 0 for empty array', () => {
      expect(calculateTotal([])).toBe(0);
    });

    it('should sum all item prices', () => {
      const items = [{ price: 100 }, { price: 200 }];
      expect(calculateTotal(items)).toBe(300);
    });
  });

  describe('edge cases', () => {
    it('should handle single item', () => {
      const items = [{ price: 100 }];
      expect(calculateTotal(items)).toBe(100);
    });

    it('should handle decimal prices', () => {
      const items = [{ price: 10.5 }, { price: 20.3 }];
      expect(calculateTotal(items)).toBe(30.8);
    });
  });

  describe('error handling', () => {
    it('should throw for negative prices', () => {
      const items = [{ price: -100 }];
      expect(() => calculateTotal(items)).toThrow('Price cannot be negative');
    });
  });
});
```

## 测试覆盖率分析

### 覆盖率缺口检测
- 检查项目是否有 jest.config / vitest.config
- 运行 `npx jest --coverage` 或 `npx vitest --coverage` 获取覆盖率报告
- 识别覆盖率 < 80% 的文件，优先生成这些文件的测试

### 测试模式学习
- 分析现有测试文件的模式（setup、mock、assertion 风格）
- 新生成的测试遵循项目已有模式
