# 错误调查 Skill

系统化调查和定位错误，从错误信息追溯到根本原因。

## 使用场景

- 运行时错误排查
- 编译错误修复
- 异常行为定位

## 调查流程

### Phase 1: 信息收集
1. 读取错误信息/堆栈跟踪
2. 定位错误发生的位置
3. 收集相关上下文代码

### Phase 2: 根因分析
1. 追溯调用链
2. 检查数据流
3. 验证假设条件
4. 识别触发条件

### Phase 3: 解决方案
1. 修复根本原因（非症状）
2. 添加防御性检查
3. 改进错误处理

## 常见错误模式

### TypeScript 类型错误
```
原因：类型定义不完整或类型断言不当
修复：补充类型定义，移除 any
```

### 运行时 TypeError
```
原因：空值/undefined 访问
修复：添加空值检查，使用可选链
```

### 模块导入错误
```
原因：路径错误、循环依赖、导出缺失
修复：检查 import 路径，确认导出
```
